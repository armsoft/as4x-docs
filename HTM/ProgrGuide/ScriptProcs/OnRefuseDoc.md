# OnRefuseDoc փաստաթղթի համակարգային իրադարձություն

OnRefuseDoc իրադարձությունը առաջանում է փաստաթուղթը չեղարկելու ժամանակ՝ RefuseDoc մեթոդով փաստաթուղթը չեղարկելիս բացվող տրանզակցիայում։

## Շարահյուսություն

```vb
Public Sub OnRefuseDoc()
    ' statements
End Sub
```
